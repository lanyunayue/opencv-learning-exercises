## 学习方法分享

### 1. 边学边练，不要光看视频

看视频的时候觉得都懂了，一写代码全忘光。**一定要动手敲代码**，哪怕是照着例子抄一遍，也比只看不练强。

### 2. 改参数，看变化

每个函数都有好几个参数，不要只记默认值。试着改一改参数，看看输出有什么变化，这样理解才深刻。

比如学 Canny 边缘检测的时候，把 threshold1 和 threshold2 调大调小，看看边缘是变多了还是变少了。

### 3. 理解原理，而不是只记 API

API 很容易忘，但原理理解了就不容易忘。比如学滤波的时候，搞清楚每种滤波的原理和适用场景，比记住函数名有用得多。

当然，不用一开始就死磕数学推导，先会用，再慢慢深入原理。

### 4. 用自己的图片测试

不要总用教程里的示例图，拿自己拍的照片、网上找的图来测试。不同的图效果可能差很多，遇到问题再去想为什么，进步最快。

### 5. 做小项目，把知识点串起来

学完一个阶段，找个小项目练手。比如学完阈值和轮廓，可以做个硬币计数的小程序。
